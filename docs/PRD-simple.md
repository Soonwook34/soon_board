# PRD (간단 버전) — soon-board

> F1 세션을 **라이브로 보거나, 지난 세션을 리플레이로 다시 볼 수 있는** 개인용 웹 타이밍 대시보드.
> 데이터는 OpenF1 공개 API 사용. 스택/아키텍처는 미정 — 이 문서는 **어떤 기능을 만들 것인가**만 정의한다.
> 사용 맥락: 데스크톱 위주, F1 방송 그래픽 느낌의 UI. **다크/라이트 테마 모두 지원** (기본 다크, 전환 토글 제공).

---

## 화면 1. 메인 페이지 — 세션 탐색 허브

보고 싶은 세션을 찾아 들어가는 유일한 진입점.

- **시즌 선택**: 연도(2023~현재)를 골라 그 시즌의 그랑프리 목록을 본다.
- **GP 그리드**: 그랑프리들이 카드로 나열된다. 카드에는 국가, 서킷명, 날짜, 상태(지남 / 라이브 / 예정 / 취소)가 보인다.
- **세션 목록**: GP 카드를 클릭하면 그 GP의 세션들(FP1~3, 퀄리, 스프린트, 레이스)이 펼쳐진다.
  - 지난 세션 → 리플레이로 진입. 호버 시 결과 미리보기(포디엄 3인, 패스티스트랩, 우천 여부).
  - 진행 중 세션 → 라이브로 즉시 진입.
  - 예정 세션 → 카운트다운 표시.
- **Hero 배너**: 지금 진행 중이거나 가장 임박한 세션 하나를 상단에 크게 — 라이브면 진입 버튼, 예정이면 카운트다운.
- **검색/필터**: GP 이름·서킷·국가 검색, 세션 타입/상태별 필터.

## 화면 2. 레이스 대시보드 — 타이밍 메인 화면

세션 전체를 한 화면에서 조망한다. 라이브와 리플레이가 같은 화면을 쓴다.

- **세션 헤더**: 트랙명·국기·세션명·현지 시각·모드 표시(LIVE / REPLAY).
- **진행률 바**: 현재 랩/총 랩(레이스) 또는 경과 시간(연습·퀄리). 적기·세이프티카 구간 표시.
- **리더보드 (20행)**: 순위 · 드라이버(팀 컬러) · 앞차 간격 · 리더 갭 · 최근 랩타임 + 섹터별 색(전체 베스트=보라, 개인 베스트=초록) · 타이어(컴파운드+랩 수) · 핏/패스티스트랩/리타이어 표시.
- **깃발 배너**: 현재 활성 깃발(옐로, 레드, SC 등) 1건 상시 표시. 중요 이벤트는 화면 상단에 잠깐 크게.
- **이벤트 티커**: 레이스 컨트롤 메시지 최근 5건.
- **타이어 전략(접이식)**: 드라이버별 스틴트를 가로 막대로 — 언제 어떤 타이어를 얼마나 썼는지.
- **패스티스트랩 존**: 세션 최고 랩 + 섹터 1/2/3 각 베스트.
- **날씨 미니 패널**: 기온, 노면 온도, 강수, 바람.

## 화면 3. 드라이버 상세 패널

리더보드 행이나 맵 마커를 클릭하면 우측에 열리는 패널. 드라이버 한 명을 깊게 본다.

- **프로필**: 헤드샷, 이름, 번호, 팀(팀 컬러), 국적.
- **현재 상태**: 순위 · 현재 랩 · 간격 · 현재 타이어 · 마지막 랩(섹터별 색 포함) · 진행 중인 랩.
- **랩 기록 테이블**: 완료한 랩들의 시간·섹터·최고 속도 (기본 5행 + 더 보기).
- **스틴트 이력**: 타이어별 사용 구간.
- **핏스톱 이력**: 몇 랩에 몇 초 걸렸는지.
- **최종 결과** (세션 종료 후에만): 순위, 총 랩, 기록, DNF/DNS/DSQ 여부.

## 화면 4. 퀄리파잉 화면 — Q1/Q2/Q3 변형

퀄리파잉(및 스프린트 퀄리파잉) 세션일 때 대시보드가 이 형태로 바뀐다.

- **퀄리 순위 타워**: 순위 기준이 갭이 아니라 **현재 세그먼트 베스트 랩타임**. 컷라인 아래 탈락권 드라이버는 빨간 음영 + DROP 표시.
- **세그먼트 진행**: Q1 → Q2 → Q3 진행 단계 표시 + 세그먼트 남은 시간 카운트다운(막판 긴박감 강조).
- **세그먼트 베스트 보드**: Q1/Q2/Q3 각각의 드라이버별 베스트를 모아보기. 세션 전체 베스트는 보라 강조.
- **랩 상태 구분**: 플라잉 랩 / 아웃 랩 / 인 랩을 구분해 표시.

## 화면 5. 서킷 맵

트랙 위 전차량 위치를 실시간으로 보여주는 패널 (대시보드 안에 포함).

- **트랙 외곽선 + 핏레인** 위에 드라이버 마커(팀 컬러 원 + 약어 라벨)가 부드럽게 이동.
- **선두 강조**, 리타이어 차량은 회색 처리, 위치 신호 끊긴 차량은 흐리게.
- **라벨 표시 토글**.

## 화면 6. 라이브/리플레이 공통 셸

대시보드와 맵을 감싸는 외곽 프레임. 라이브/리플레이 차이는 여기서만 드러난다.

- **공통**: 세션명, 시계, 스트림 상태 배지(정상 / 지연 / 끊김 / 버퍼링).
- **라이브 전용**: 세션 시작 전이면 전체 화면 카운트다운 오버레이 → 시작 시 자동 전환. (라이브는 방송처럼 약 30초 지연으로 재생)
- **리플레이 전용 — 재생 컨트롤 바**: 재생/일시정지, 시크 바, ±15초 점프, 배속(0.5 / 1 / 2 / 4배).
- **오류 안내**: 데이터를 못 불러올 때(광고 차단기 등) 원인 안내 + 재시도.
