# soon-board 디자인 브리프 — 데이터 제약 반영 체크리스트

> **용도:** claude design에 전달하는 문서. 이미 만들어진 디자인을 아래 체크리스트로 **감사(audit)하고 위반 지점을 수정**하기 위한 것.
> **이 문서 하나로 충분하다** — 감사에 필요한 제약이 전부 이 안에 있으므로 다른 문서를 요청하지 말 것. (근거 출처는 repo의 `PRD-simple.md` · `openf1-api-reference.md` · `infra-architecture.md`이며, 이 브리프는 그중 UI에 영향을 주는 제약만 추린 완결본이다.)

## 0. 전 화면 공통 전제

| # | 제약 | 디자인 반영 |
|---|---|---|
| C1 | **리플레이 전용으로 시작** (라이브는 추후 유료 활성화) | 라이브 진입점은 존재하되 "준비 중/비활성" 상태 디자인. 라이브 전제의 실시간 배지·카운트다운을 기본 상태로 두지 말 것 |
| C2 | 시청 가능 시점 = **세션 종료 +30분 후 수집 완료 시** | 최근 세션에 "수집 대기 중" 상태 필요 (탐색 허브·세션 카드) |
| C3 | **"데이터 없음/부분/끊김"이 1급 상태** — API는 조건 미일치 시 404(정상), 수집도 partial 가능 | 모든 위젯에 빈 상태(empty)·부분 데이터 안내 디자인. 스켈레톤/플레이스홀더 포함 |
| C4 | 갭·간격 값은 **숫자 \| `"+N LAP(S)"` 문자열 \| null** 3종 | 리더보드/결과의 갭 셀에 랩다운 문자열 표기 케이스 반영 (숫자 정렬 컬럼에 문자열 섞임) |
| C5 | 순위·리더 판정은 `position` 데이터 기준, **확정 결과는 별도**(`session_result`, 페널티 반영) | "잠정 순위 ↔ 확정 결과" 상태 전환 표시 (레이스 종료 직후 잠정 라벨) |
| C6 | **국적 데이터 없음** (country_code 폐지·2026년 이미 null) | 국기 아이콘에 의존한 레이아웃 금지 (자체 매핑 도입 전까지 생략 가능해야 함) |
| C7 | 드라이버 헤드샷 일부는 **fallback 이미지** | 실루엣 플레이스홀더 디자인 |
| C8 | 팀 컬러는 `#` 없는 HEX 문자열로 제공 | 팀 컬러 바/액센트는 그대로 활용 가능 |
| C9 | 텔레메트리(속도·RPM·기어)·팀라디오는 **범위 제외** | 관련 위젯이 디자인에 있으면 제거 |
| C10 | 데이터 출처 표기 의무 (CC BY-NC-SA) | 푸터에 "Data: OpenF1 (unofficial)" 크레딧 자리 |

## 화면별 체크리스트

### 1. 세션 탐색 허브
- 탐색 구조: 시즌 → GP 주말 → 세션 (재래식 5세션 / 스프린트 주말은 P1·스프린트 퀄리·스프린트·퀄리·레이스 구성 — 주말 유형 구분 표기)
- 세션 카드 상태 3종: **시청 가능 / 수집 대기(종료 직후) / 데이터 없음**
- 프리시즌 테스트는 목록에 없음 (수집 제외)

### 2. 레이스 대시보드 (리더보드·플래그·티커·타이어 전략·날씨)
- 리더보드: 갭 컬럼에 C4(랩다운 문자열)·인터벌 초반 수 랩 공백 케이스
- 플래그 상태: GREEN / YELLOW / DOUBLE YELLOW / RED / SC·VSC(race_control 메시지 기반) / CHEQUERED — 전환 애니메이션보다 **현재 상태 명확성 우선**
- 티커: race_control 메시지는 **자유 텍스트** (길이 가변, 파싱 불가) — 말줄임+펼침. category/flag 뱃지로 분류 표시
- 타이어 전략: compound 5종 (SOFT·MEDIUM·HARD·INTERMEDIATE·WET) 컬러 코드 + 장착 시점 age("중고" 표시) + 스틴트 바 차트
- 날씨: 기온·노면온·습도·풍속/풍향·강수. **강수는 유/무(0/1)만** — 강수량 게이지 금지

### 3. 드라이버 상세 패널
- 랩 테이블: 랩타임·섹터 3개·미니섹터 색상 스트립
- **미니섹터 색 매핑: 보라=오버롤 베스트, 초록=개인 베스트, 노랑=그 외, 회색/무색=데이터 없음·핏레인** (TV 그래픽과 1:1이 아님)
- 아웃랩(핏아웃) 구분 표시, 미완성 랩의 null 타임 표기
- 스피드트랩(i1/i2/ST) 표시 가능

### 4. 퀄리파잉 변형
- **인터벌 데이터 없음** (레이스 전용) — 갭은 베스트 랩타임 차이로 계산·표기
- Q1/Q2/Q3 세그먼트 탭/타임라인 + **컷라인**(탈락선) + 녹아웃 표시
- 결과의 Q1/Q2/Q3 타임은 미진출 단계가 빈 값 — "—" 표기
- 세션 내 현재 단계는 race_control의 qualifying_phase 기반
- 트랙 진화(막판 기록 경신 몰림) 특성상 순위 변동 하이라이트 유용

### 5. 서킷 맵
- 트랙 아웃라인은 MultiViewer 지오메트리 사용 (좌표계는 차량 위치와 동일)
- **서킷별 원점·방향이 제각각** — 자동 fit/회전 전제, 고정 방위 표기(N 화살표) 금지
- 차량 마커: 3.7 Hz 데이터 + 클라이언트 보간으로 부드럽게. **(0,0,0) 좌표는 숨김**(가라지/신호 없음)
- 마커에 드라이버 약어(NOR 등)·팀 컬러

### 6. 라이브/리플레이 공통 셸
- 리플레이 컨트롤: 재생/일시정지·배속·스크럽 바·키 모먼트 점프(플래그·핏 이벤트 마커)
- 진입 로딩: 세션당 ~7.5 MB 청크 병렬 다운로드 — **프로그레스 표시** (스피너 금지)
- 라이브 토글: C1 — "준비 중" 상태 디자인만
- (라이브 활성화 대비) 재생 위치 기준 "몇 분 지연" 표시 자리만 예약

## claude design에 줄 지시문 (예시)

> 첨부한 체크리스트(C1~C10 + 화면별 항목)로 기존 화면 6종을 감사해줘. 각 항목에 대해 ①이미 충족 ②수정함 ③해당 없음 중 하나로 보고하고, 위반 항목은 디자인을 수정해. 특히 퀄리파잉 화면의 인터벌 표기(항목 4), 텔레메트리 위젯 존재 여부(C9), 빈 상태/수집 대기 상태(C2·C3) 누락을 우선 확인해줘.
